# How to Use Parental Controls to Limit Internet Time

**Article:** KB-17 · **Category:** Equipment & Network Settings · **Applies to:** BlazzRouter R100, R200

Parental controls let you decide when certain devices in your home can use the internet — for example, turning off a child's tablet at bedtime. You set them up on your router, so they work no matter which app is being used.

Both the BlazzRouter R100 and BlazzRouter R200 support parental controls.

## How to set up a schedule

1. On a device connected to your home network, open a web browser and go to **192.168.1.1**.
2. Log in with your router admin password. It's printed on the router sticker, unless you changed it.
3. Select **Parental Controls**.
4. Choose a device from the list of devices connected to your network.
5. Set the hours when that device can't use the internet — for example, 9 p.m. to 7 a.m. on school nights.
6. Select **Save**.

You can set a different schedule for each device.

## Pause the internet right away

On the Parental Controls page, select a device and choose **Pause**. It stays offline until you choose **Resume**.

## Tips

- **Rename devices on the list** so they're easy to find. A phone might first show up as a string of letters and numbers.
- **Cover every device a child uses** — phone, tablet, laptop, and game console.
- **Check the list now and then** for new devices.

## Good to know

- **Parental controls only work on your home internet.** If a phone switches to mobile data, the router's controls don't apply.
- **A blocked device still looks connected.** During blocked hours, it shows as connected to Wi-Fi but can't load anything. If a device in your home can't get online at the same time every day, check whether it has a parental control schedule.
- **A factory reset erases all parental control settings.** See "Forgot Your Router Admin Password?"
